# Mr. WashWala Documentation Hub

Welcome to the comprehensive documentation repository for the **Mr. WashWala** multi-client laundry management and booking platform.

## Documentation Structure

The documentation is organized into clear functional categories:

```text
client/docs/
├── phase-reports/          # Phased development, implementation, and audit reports (Phases 1 - 9A)
├── architecture/           # System architecture diagrams and setup guides (Reviews, Maps, Systems)
├── api-research/           # API contracts, data source audits, and research reports
├── website-screenshots/    # Visual captures and audits of the React/Vite website
└── mobile-screenshots/     # Device captures, test runs, and icon assets of the Flutter mobile app
```
