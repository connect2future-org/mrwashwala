# Mobile Screenshots & Visual Assets

This directory stores visual captures, UI audit screenshots, and launcher icon previews from the **Mr. WashWala** Flutter mobile application (Android / iOS).

## Contents

- **`screen_p10_*.png`**: Phase 10 / Customer Journey verification screens (Home, Services, Details, Cart, Checkout, Profile).
- **`screen_price_list_*.png`**: Price list view and scroll audit captures.
- **`screen_subscription_plans*.png`**: Subscription plans screen captures.
- **`screen_profile*.png`**: Profile, address, and order management screen captures.
- **`preview_icon_*.png` & `test_trans.png`**: Android adaptive launcher icon previews and transparency checks.
